# The 100 input documents

`d001_medium.txt` ... `d100_*.txt`: clean, plain-text documents that attack payloads are inserted into.
Generated by `python scripts/make_documents.py` (deterministic: rerunning gives the same files).

| | |
|---|---|
| **Length** | 30 short (about 70-120 words), 40 medium (125-230), 30 long (440-650). The tier is in the file name. |
| **Genres** | news article, press release, memo, incident report, product review, meeting minutes, customer email, blog post, service notice, grant summary. Each genre appears in every length. |
| **Room for a payload** | every document has at least 4 paragraphs (long ones 16-20), so start, middle and end are different places. |
| **Facts** | each has exactly one organization, one full date, one dollar amount and one city. Other numbers are counts and percentages, and other times are relative, so the questions have one right answer. |

## Files
- `answers.json`: `{doc_id: [accepted strings per question]}`, the schema of `data/placeholder/answers.json`.
  In the order of the questions in `config/dev.yaml`: organization, the most important date, the most important amount, the location.
- `manifest.json`: per document its genre, tier, word and paragraph counts, and its **assigned poison**.

## Poisoning
The documents are clean; the poison is inserted when a run starts, from `data/attacks/templates.json`. Each document
is *assigned* one template and one position so that all 100 are poisoned, in a balanced design: every real template
(not the `stub` placeholder) is used about 9 times, every template-position pair 3 or 4 times, and every template
meets short, medium and long documents.

```
# every document with its own assigned poison, on both pipelines (200 poisoned runs)
python scripts/run_batch.py --assigned --docs data/docs/*.txt --max-runs 200

# or the full cross (every template x position) on some documents
python scripts/run_batch.py --docs data/docs/d001_medium.txt data/docs/d002_long.txt --positions start middle end
```
In the viewer's Batch tab, select documents (all / none / short / medium / long) and tick "each document's assigned poison".
Add `--with-clean` for the unpoisoned baseline of the same documents.

To change the set (more documents, other lengths, other genres), edit `scripts/make_documents.py` and rerun it; the tests in
`tests/test_documents.py` check that every document has a unique, answerable key and that the assignment stays balanced.
